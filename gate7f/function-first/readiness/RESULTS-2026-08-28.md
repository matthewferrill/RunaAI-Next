## Context and deadline limits

Qwen returned a28-token answer to4,770 prompt tokens in17.740s. The first14,270-token request timed out
at30.004s. After two low-utilization samples, a separately labelled120s diagnostic returned in9.458s.
Repeated prompt/cache state can affect that retry; it does not erase the failed30s request or qualify
14k cold prompts for30s. The22k ladder was not attempted after the first timeout. GPU idleness is not a
server cancellation acknowledgement, so endpoint cancellation/exclusive scheduling remains a separate
application-runtime responsibility.

One small successful response at a particular context is not a general latency SLO for every function.
Cold model loading, prompt processing and token generation must remain separate in product reporting.
One-owned-model residency was checked; exclusive traffic to the shared LM Studio endpoint was not
independently proven. The captures explicitly retain `exclusiveTrafficVerified:false`.
